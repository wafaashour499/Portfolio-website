Case Study

Egyptian Museum AI Guide

A bilingual RAG assistant for exploring ancient Egyptian artifacts

Overview

Visitors can ask about any artifact, king, or museum in Arabic or English, and the system searches a real artifacts database covering the Egyptian Museum in Cairo, the Luxor Museum, the Nubian Museum, and the Grand Egyptian Museum. It retrieves the most relevant pieces through semantic search, then generates a complete answer grounded in that retrieved data combined with the model's historical knowledge.

My Contributions

  • Data Collection & Embedding Pipeline
  • Vector Database Construction (ChromaDB)
  • Semantic Search & Prompt Engineering
  • Streamlit Interface & Deployment

Key Features

Multilingual Semantic Search

Ask in Arabic or English and get the same accurate results.

Streaming Responses

Answers appear progressively instead of a blocking wait.

Cited Sources

Every answer links directly to the matching Wikidata entry.

Virtual Tours

Automatic Matterport 3D tour links when a site has one available.

Image Fallback

Broken image links gracefully fall back to a placeholder.

User Feedback

Thumbs up/down on every response for continuous improvement.

Movie Industry EDA with Python

Exploring Hollywood's profitability secrets across 6,000+ films

Overview

This project turns a large, messy dataset of over 6,000 films into an interactive report that reveals what really drives profitability in Hollywood, combining data cleaning, feature engineering, and statistical analysis to surface insights hidden in the raw numbers.

My Contributions

  • Data Cleaning: handled missing values, standardized date formats, and resolved duplicates to ensure data quality.
  • Feature Engineering: created new metrics such as net profit, ROI, and release season for deeper analysis.
  • Correlation Analysis: used correlation heatmaps to uncover the real drivers of revenue.
  • Outlier Analysis: explained low-budget hits and streaming-platform underperformers (e.g. Netflix titles) with data.
  • Visualization: turned raw numbers into professional charts that support clear decision-making.

Key Features

Data Cleaning
